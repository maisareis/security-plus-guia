## 📊 Estatísticas

- 📖 **13 capítulos** com flashcards interativos
- 🎯 **5 domínios** da certificação organizados
- 📝 **13 resumos detalhados** com dicas para prova
- ❓ **340+ questões comentadas**
- ⚡ **Desafio rápido** com timer de 15 minutos

## 🚀 Acesse o projeto

## 📌 Sobre

Este projeto foi criado como método de estudo para a certificação CompTIA Security+. 
Todo o conteúdo foi desenvolvido com base nos objetivos do exame, utilizando:

- ✅ Flashcards por capítulo para revisão rápida
- ✅ Resumos com os conceitos mais importantes
- ✅ Questões comentadas para fixar o conteúdo
- ✅ Simulados por domínio e desafio rápido

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3 (com gradientes e design responsivo)
- JavaScript vanilla (sem frameworks)
