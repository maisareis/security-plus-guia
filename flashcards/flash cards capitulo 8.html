1️⃣ Hardening de SO

  • Remover software desnecessário - reduz superfície de ataque
  • Desabilitar serviços não usados - menos portas abertas
  • Patches e updates automáticos - correção de vulnerabilidades
  • Firewall habilitado - controle de tráfego
  • Antivírus atualizado - proteção contra malware
  • Políticas de senha fortes - complexidade, comprimento
  • UAC habilitado (Windows) - User Account Control
  • Least privilege - mínimas permissões necessárias
  • Secure Boot - protege contra rootkits de boot
  • Measured Boot - registra hashes do boot para verificação

2️⃣ NTFS Permissions (Windows)

PermissãoDescrição
ReadLer arquivos/pastas
WriteEscrever/modificar

⚠️ REGRAS DE OURO NTFS:
  • Deny sempre prevalece sobre Allow
  • Explicit > Inherited

Linux Host Security

  • iptables: firewall do Linux. Chains: INPUT, OUTPUT, FORWARD
  • Desabilitar serviços: systemctl disable nome-do-serviço
  • SSH hardening: desabilitar login root, usar autenticação por chaves

3️⃣ Wireless Security

Ataques Wi-Fi

  • Evil Twin: AP falso com mesmo SSID do legítimo. MITM.
  • Rogue AP: AP não autorizado conectado à rede.
  • Deauth Attack: Força desconexão de clientes.
  • WPS Attack: PIN de 8 dígitos vulnerável a brute force.
  • War Driving: Mapear redes Wi-Fi.
  • KRACK Attack: Vulnerabilidade no WPA2 que permite reutilização de nonces.

Proteções Wi-Fi

PadrãoSegurança
WPA3SAE, protege contra ataques offline de dicionário
WPA2AES-CCMP, vulnerável a KRACK
WPATKIP (inseguro)
WEPTotalmente inseguro
  • 802.1X (Enterprise): RADIUS + EAP para autenticação corporativa
  • WIPS: Detecta rogue APs e evil twins
  • EAP-TLS: Certificados no cliente e servidor (mais seguro)
  • PEAP: Túnel TLS com certificado apenas no servidor

6️⃣ Desenvolvimento Seguro

SDLC

  1. Requirements - requisitos de segurança
  2. Design - threat modeling
  3. Development - codificação segura
  4. Testing - SAST, DAST
  5. Deployment - hardening
  6. Maintenance - patches

Conceitos

  • DevSecOps: Shift left (segurança no desenvolvimento)
  • SAST: Análise estática (código fonte)
  • DAST: Análise dinâmica (aplicação rodando)
  • AppLocker: Application whitelisting no Windows
  • DEP: Data Execution Prevention - anti-buffer overflow
  • ASLR: Address Space Layout Randomization
  • Code Signing: Assinar código com certificado

7️⃣ Arquiteturas Modernas

  • Microservices: Serviços pequenos e independentes
  • Containerização: Docker, Kubernetes
  • Serverless (FaaS): AWS Lambda, Azure Functions
  • IaC: Infrastructure as Code (Terraform)
  • API Gateway: Proxy para APIs

8️⃣ Network Security

Switch Security

  • Port Security: Limita MACs por porta (MAC flooding)
  • DHCP Snooping: Previne DHCP spoofing
  • DAI: Dynamic ARP Inspection (ARP poisoning)
  • BPDU Guard: Desabilita porta se receber BPDU
  • Root Guard: Protege spanning tree topology
  • Storm Control: Limita broadcasts

Segmentação

  • Network Segmentation: VLANs, subnets
  • Microsegmentation: Firewall entre workloads (Zero Trust)
  • Private VLANs: Isola portas na mesma VLAN
  • DMZ: Screened subnet entre dois firewalls
  • Jump Server: Bastion host para acesso interno

9️⃣ Autenticação e Controle de Acesso

  • Geofencing: Restrição por localização
  • Time-based Access: Restrição por horário
  • Remote Wipe: Apagar dados remotamente
  • Biometria: Impressão digital, face ID
  • Passwordless: FIDO2, Windows Hello
  • Context-aware Auth: Baseada em contexto
  • Step-up Auth: Autenticação adicional para ações sensíveis
  • Continuous Auth: Verificar usuário continuamente
  • Zero Trust: "Never trust, always verify"

🔟 Proteções Avançadas do Windows

  • UAC: User Account Control
  • Device Guard: Isolamento por virtualização
  • Credential Guard: Protege contra pass-the-hash
  • Secure Boot: Verifica integridade do boot
  • Measured Boot: Registra hashes do boot
