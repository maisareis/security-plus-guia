📖 Resumo - Capítulo 6

🎯 CONCEITOS MAIS IMPORTANTES PARA PROVA:
  • IDS vs IPS: IDS detecta e alerta (passivo), IPS detecta e bloqueia (ativo/inline)
  • Passive vs Active Recon: Passivo não toca no alvo (OSINT), ativo interage (port scan)
  • Rainbow Table vs Salt: Rainbow table = tabela pré-computada, SALT torna inútil
  • False Negative (não detectar ataque) é MAIS GRAVE que False Positive
  • SNMP v3 é seguro (criptografia), v1/v2c são inseguros (community strings texto claro)

1️⃣ Controles Físicos

Perímetro e Acesso

  • Mantrap: Duas portas, apenas uma aberta por vez. Previne tailgating (seguir pessoa autorizada).
  • Bollards: Postes/colunas para impedir entrada de veículos. Protege contra ataques de vehicle ramming.
  • Biometric Scanner: Impressão digital, íris, face para controle de acesso.
  • Security Guard: Vigilância humana, pode tomar decisões em tempo real.
  • CCTV: Câmeras de vigilância, monitoramento contínuo.

Proteção de Equipamentos

  • Faraday Cage: Gaiola que bloqueia sinais eletromagnéticos. Previne eavesdropping (escuta clandestina).
  • Cable Lock: Trava física para laptops. Previne roubo rápido.
  • Safe: Cofre para backups e documentos.
  • USB Data Blocker: Previne juice jacking (carga sem dados).

2️⃣ Monitoramento de Rede

Protocolos de Monitoramento

  • SNMP: Simple Network Management Protocol. UDP 161 (queries), 162 (traps). v1/v2c inseguro (community strings texto claro), v3 com criptografia.
  • NetFlow: Coleta metadados de tráfego (IPs, portas, protocolos, volume). Não captura payload.
  • sFlow: Similar ao NetFlow, usa amostragem de pacotes.
  • Syslog: Logs centralizados, UDP 514. Severity levels (0-7).
  • SIEM: Security Information and Event Management. Correlaciona logs, detecta ameaças, gera alertas.

3️⃣ Reconhecimento (Reconnaissance)

👀 Passive Recon

Não interage diretamente com alvo. Difícil detectar.

  • OSINT (Google, redes sociais)
  • DNS lookups (whois, nslookup)
  • Shodan (dispositivos IoT)
  • Job postings (tecnologias usadas)

🎯 Active Recon

Interage com alvo. Pode ser detectado.

  • Port scanning (nmap)
  • Ping sweep
  • Banner grabbing
  • Vulnerability scanning

4️⃣ IDS/IPS

🛡️ IDS

  • DETECTA e ALERTA
  • Modo passivo (out-of-band)
  • Recebe cópia do tráfego (span port)
  • Não afeta desempenho

⚡ IPS

  • DETECTA e BLOQUEIA
  • Modo ativo (inline)
  • Tráfego passa por ele
  • Pode adicionar latência

Métodos de Detecção

  • Signature-based: Compara com assinaturas conhecidas. Rápido, baixo falso positivo, mas só detecta conhecido.
  • Anomaly-based: Detecta desvios do baseline normal. Detecta novos ataques, mas mais falsos positivos.
  • Behavior-based: Analisa comportamento. Similar a anomaly.
  • Heuristic: Regras baseadas em conhecimento de ataques.

Ações do IPS

  • Alert: Apenas alerta (modo IDS)
  • Drop: Descarta pacote silenciosamente
  • Reject: Descarta e envia RST/ICMP unreachable
  • Quarantine: Isola host suspeito (VLAN de quarentena)

5️⃣ Analisadores de Protocolo

Wireshark

  • Capture Filter: Antes de capturar (BPF syntax). Ex: host 192.168.1.1
  • Display Filter: Após capturar (Wireshark syntax). Ex: tcp.port == 80
  • Follow Stream: Reconstroi conversa TCP/UDP

tcpdump

  • Linha de comando, Linux/Unix
  • tcpdump -i eth0 (interface específica)
  • tcpdump -w arquivo.pcap (salvar captura)

⚠️ REGRA DE OURO:
  • DoS: Uma fonte | DDoS: Múltiplas fontes (botnet)
  • ARP Poisoning → DAI
  • MAC Flooding → Port Security
  • DHCP Spoofing → DHCP Snooping

7️⃣ Ataques de Senha

Tipos de Ataques

  • Brute Force: Testa todas combinações possíveis. Lento, mas efetivo com senhas curtas.
  • Dictionary Attack: Usa lista de palavras comuns. Rápido contra senhas fracas.
  • Hybrid Attack: Dicionário + variações (password123, Password!)
  • Rainbow Table: Tabela hash→plaintext pré-computada. Muito rápido, mas inútil com salt.
  • Credential Stuffing: Usa senhas vazadas de outros sites (reuso de senhas).
  • Password Spraying: Tenta senha comum em muitas contas (evita lockout).

Ferramentas de Quebra de Senhas

  • John the Ripper: Cracker multiplataforma, vários modos (single, wordlist, incremental)
  • Hashcat: Cracker usando GPU, muito rápido, suporta muitos algoritmos
  • Hydra: Online password cracker, testa serviços (SSH, FTP, HTTP)
  • Ophcrack: Usa rainbow tables, especializado em Windows

Proteções

  • Salt: Valor aleatório único por senha adicionado antes do hash. Torna rainbow table inútil.
  • Key Stretching: PBKDF2, bcrypt, Argon2 - múltiplas iterações, dificulta brute force.
  • Account Lockout: Bloqueia após X tentativas. Previne brute force online.
  • MFA: Protege mesmo se senha comprometida.
💡 DIFERENÇA CRÍTICA:
  • Online Attack: Contra serviço ativo (lento, detectável, limitado por lockout)
  • Offline Attack: Contra hash capturado (rápido, indetectável, ilimitado)

Pass-the-Hash

  • Usa hash da senha diretamente (sem quebrar)
  • Comum em Windows (NTLM)
  • Contramedidas: Kerberos, Credential Guard, limitar admin local

🎯 DICAS FINAIS PARA PROVA:

  • IDS = alerta (passivo) | IPS = bloqueia (ativo)
  • Passive recon = OSINT, DNS lookups | Active recon = port scan, ping sweep
  • Rainbow table funciona sem salt, com salt é inútil
  • False negative (não detectar ataque) é MAIS GRAVE que false positive
  • SNMP v1/v2c inseguro, v3 seguro
  • ARP poisoning → DAI | MAC flooding → Port Security
  • Online attack é lento e detectável, offline é rápido e indetectável
  • PBKDF2, bcrypt, Argon2 = key stretching (dificulta brute force)
