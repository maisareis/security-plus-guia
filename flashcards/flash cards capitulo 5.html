1️⃣ Arquitetura de Rede

Three-Tier Architecture

  • Core Layer: Backbone alta velocidade, roteamento entre segmentos
  • Distribution Layer: Políticas, ACLs, filtragem, agregação
  • Access Layer: Conecta usuários finais, switches de acesso

Modelo OSI Essencial

  • Layer 1 (Physical): Cabos, sinais elétricos/ópticos, wireless
  • Layer 2 (Data Link): Switches, APs, MAC address (48-bit)
  • Layer 3 (Network): Routers, IP addresses, default gateway
  • Layer 4 (Transport): TCP (confiável), UDP (não confiável), portas
  • Layer 7 (Application): HTTP, FTP, SMTP, DNS

On-Premises vs Cloud

  • On-Prem: Alto CapEx, controle total, baixa escalabilidade
  • Cloud: OpEx, alta escalabilidade, menos controle, melhor resiliência

2️⃣ Defense in Depth

  • Preventivo: Firewall na borda (bloqueia antes de entrar)
  • Detectivo: IDS dentro do perímetro (alerta sobre ameaças)
  • Corretivo: Load balancer (mitiga DDoS), endpoint protection
  • Active: Requer config (firewall como gateway)
  • Passive: Transparente (TAP, mirror port)
  • Fail-Open: Mantém acesso → prioriza AVAILABILITY
  • Fail-Closed: Bloqueia acesso → prioriza CONFIDENTIALITY

3️⃣ Screened Subnet (DMZ) ⭐ CRÍTICO

💡 Configuração:
  • Firewall Externo: Internet → DMZ
  • DMZ: Web server, FTP, Email público, DNS público
  • Firewall Interno: DMZ → LAN privada

Conceitos Chave

  • Dual-Homed Gateway: 3 interfaces (internet, DMZ, LAN)
  • Screening Router: Router + firewall (ACLs), mais externo
  • Bastion Host: Servidor fortificado exposto à internet
  • Screened-Host Gateway: Na DMZ, requer autenticação
  • Packet Filters: Permitem tráfego para recursos públicos na DMZ
⚠️ REGRA DE OURO:
  • Se firewall EXTERNO falha → Apenas DMZ comprometida (LAN protegida!)
  • Web server público → DMZ
  • Database → LAN privada (firewall interno permite só tráfego do web)
  • VPN server → pode ficar na DMZ

4️⃣ Firewalls

Tipos

  • Stateless (Packet Filter): Analisa cada packet independente, IP/porta/protocolo
  • Stateful: Rastreia estado de conexões TCP, state table
  • Layer 4: Examina TCP handshake (SYN/SYN-ACK/ACK)
  • Layer 7 (Application): Inspeciona headers + payload, verifica protocol/port match
  • NGFW: Firewall + IPS + DPI + TLS inspection + threat intel
  • WAF: Web Application Firewall - SQL Injection, XSS, CSRF
  • UTM: All-in-one (firewall + antimalware + IPS + spam + VPN)

Regras de Firewall

  • Processamento: Top-down sequencial
  • Ordem: Específicas ANTES de gerais
  • Implicit Deny: Última regra nega tudo não permitido
  • Best Practice: Fechar TODAS portas, abrir apenas necessárias

5️⃣ VPN ⭐ CRÍTICO

🎯 PARA PROVA: VPN é a MELHOR solução para permitir acesso seguro a recursos privados da internet!

Tipos

  • Site-to-Site: Conecta redes (matriz-filial), routers nas bordas, sempre ativa
  • Remote Access: Usuários individuais → VPN concentrator
  • Split Tunnel: Corporativo via VPN, resto via internet (RISCO: bypass políticas)
  • Full Tunnel: Todo tráfego via VPN (mais seguro)
  • Always-On: Sempre na VPN, não liga/desliga

Protocolos

  • IPSec: Transport mode (host-to-host, só payload) vs Tunnel mode (site-to-site, pacote inteiro)
  • AH: Authentication Header, ICV hash, sem criptografia
  • ESP: Encapsulating Security Payload, criptografa
  • IKE: Phase 1 (identifica peers, canal seguro) + Phase 2 (negocia ciphers)
  • L2TP/IPSec: L2TP tunneling + IPSec encryption
  • TLS VPN: Certificados digitais, mutual auth, porta 443

6️⃣ NAC (Network Access Control) ⭐

Zero-Trust Security

  • Authentication: Define prerequisites (antivirus, OS, patches)
  • Authorization: Aplica políticas apropriadas
  • Zero-Trust: Nada trusted unless passa AMBOS

Implementação

  • Agent-based: Software no device, info detalhada, auto-remediation
  • Agentless: Port-based/scan, funciona com guests/IoT
  • Persistent: Instalado permanente
  • Nonpersistent: Loaded na memória, removido após assessment
  • Dynamic VLAN: NAC atribui VLAN por compliance, quarantine se necessário

Processo: Plan → Define → Apply → Review

7️⃣ Switch Security

Ataques

  • MAC Flooding: Inunda CAM table → switch vira hub
  • ARP Spoofing: Atacante associa seu MAC com IP vítima (MitM)
  • VLAN Hopping: Salta entre VLANs (double tagging)
  • DHCP Spoofing: DHCP falso fornece gateway malicioso
  • MAC Spoofing: Muda source MAC, bypass 802.1x/MAC filtering

Proteções

  • Port Security: Limita MACs por porta → previne MAC flooding
  • DHCP Snooping: Identifica portas com DHCP legítimo
  • DAI: Dynamic ARP Inspection, valida ARPs → previne ARP spoofing
  • 802.1X: Port authentication (EAP + RADIUS)
  • Desabilitar DTP: Dynamic Trunking Protocol não seguro

VLANs

  • VLAN: Segmentação lógica, cada port = 1 VLAN
  • Trunk Port: Membro de TODAS VLANs, 802.1Q tagging
  • Inter-VLAN: Por padrão NÃO comunicam, precisa router/L3 switch
  • Spanning Tree: Previne loops, 1 path ativo + backups blocked

8️⃣ Router Security

ACLs

  • Standard (1-99): Filtra apenas IP origem, perto do DESTINO
  • Extended (100-199): IP origem/dest + portas + protocolo, perto da ORIGEM
  • Wildcard Mask: Inverso subnet mask (0=match, 255=ignore)
  • Nova ACL: Por padrão BLOQUEIA TUDO (implicit deny)

Best Practices

  • SSH não Telnet: Criptografado vs texto claro
  • SCP não FTP/TFTP: Para backups seguros
  • Update firmware PRIMEIRO: Após trocar defaults
  • Physical security: Locked room (sem isso, passwords inúteis)
  • Anti-spoofing rules: Bloqueia packets externos fingindo ser internos
  • Segmentation: Divide network para conter breaches

9️⃣ Application Security

Application Control

  • Signatures: Identifica apps por inspection de packet contents
  • Flag: Permite mas loga violation (monitoring)
  • Block: Não permite, session dropped/reset
  • Tarpit: Conexão alive mas data dropped (app não percebe block)

Vulnerability Management

  • Vulnerability Scanning: Non-intrusive, analisa sem exploitar
  • App Vuln Scanning: Static (code sem executar) + Dynamic (running)
  • SBOM: Software Bill of Materials - lista components
  • SCA: Software Composition Analysis - identifica dependencies + vulns
  • Package Monitoring: Track third-party packages, automated SCA tools

🔟 Vulnerabilidades Comuns

  • Default Credentials: Trocar IMEDIATAMENTE (públicos online)
  • Complex Passwords: 8+ chars, mix types, não words/username
  • Privilege Escalation: User normal acessa funções admin (explora bug)
  • Backdoor: Hard-coded passwords, hidden accounts, added por devs/atacantes
  • Zero-Day: Vuln desconhecida, sem patch, muito perigosa (valem milhões)

1️⃣1️⃣ Hardening & Baselines

  • Attack Surface Reduction: Remove unnecessary services/software
  • Role Separation: Services em separate physical systems
  • Configuration Baseline: Consistent requirements para devices
  • Security Templates: Apply settings para multiple computers
  • Least Privilege: Privileges mínimos necessários
  • Test First: Test patches em environment antes production
  • WSUS + Group Policy: Automated patch distribution

1️⃣2️⃣ Security Solutions

Appliances

  • Proxy: Forward (protege clients) vs Reverse (protege servers)
  • Load Balancer: Distribui traffic, fault tolerance, pode incluir WAF
  • Jump Server: Hardened gateway para access isolated systems
  • Sensor: Packet sniffer (TAP ou SPAN/mirror port)
  • IDS: Passive, detecta e alerta
  • IPS: Inline, detecta e bloqueia

Deception Technologies

  • Honeypot: Sistema isca individual
  • Honeynet: Rede completa de decoys
  • Honeyfile: File trap (ex: passwords.txt)
  • DNS Sinkhole: Redireciona malicious traffic, fornece false DNS info
  • Fake Telemetry: Spoofed data em response a probes

Security Zones

  • Screened Subnet/DMZ: Buffer entre internet e LAN
  • Intranet: Private LAN com internet services (interno)
  • Extranet: Parte da network para partners/suppliers
  • Guest Network: Internet only, firewall regulado
  • Air-Gapped: Isolamento físico completo (root CA, malware analysis)
