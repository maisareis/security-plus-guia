1️⃣ Virtualização

Hypervisors

TipoDescriçãoExemplos
Type 1 (Bare Metal)Executa diretamente no hardware. Melhor performance, mais seguro.VMware ESXi, Microsoft Hyper-V, Xen, KVM
Type 2 (Hosted)Executa sobre um sistema operacional. Para desenvolvimento/teste.VMware Workstation, VirtualBox, Parallels

Ameaças em Virtualização

  • VM Sprawl: Proliferação descontrolada de VMs sem gerenciamento. Dificulta inventário e patches.
  • VM Escape: Ataque onde um processo dentro da VM consegue comprometer o hypervisor. Raro, mas crítico.

Containers vs VMs

  • Containers: Compartilham o kernel do host. Mais leves, inicialização rápida. Isolamento em nível de processo.
  • Container Security: Image scanning, least privilege, network segmentation, runtime protection.

Virtual Networking

  • vSwitch (Virtual Switch): Switch virtual que conecta VMs entre si e com a rede física.
  • NIC Teaming (Bonding): Agregação de múltiplas placas de rede para balanceamento de carga e failover.
  • VLAN: Segmentação lógica de rede em switches físicos ou virtuais.

SDN (Software-Defined Networking)

  • Control Plane: Tomada de decisão (roteamento, políticas). Centralizado.
  • Data Plane: Encaminhamento de pacotes. Segue regras do control plane.
  • Northbound API: Comunicação control plane → aplicações (REST).
  • Southbound API: Comunicação control plane → data plane (OpenFlow, NETCONF).

2️⃣ Cloud Services

Modelos de Serviço

ModeloCliente gerenciaProvedor gerenciaExemplos
SaaSNada (só usa)TudoGmail, Office 365, Salesforce
PaaSAplicação + dadosPlataforma + runtime + OS + infraHeroku, Google App Engine
IaaSOS + aplicação + dadosVirtualização + hardwareAWS EC2, Azure VMs

Modelos de Implantação Cloud

  • Public Cloud: Recursos compartilhados (multi-tenant). AWS, Azure, Google Cloud.
  • Private Cloud: Nuvem exclusiva da organização. Mais controle, mais caro.
  • Hybrid Cloud: Combinação de pública e privada. Portabilidade de workloads.
  • Community Cloud: Compartilhada por organizações com interesses comuns (ex: governos, saúde).

3️⃣ Mobile Device Management

  • MDM (Mobile Device Management): Gerenciamento centralizado: políticas, remote wipe, distribuição de apps.
  • MAM (Mobile Application Management): Gerenciamento de aplicações específicas (app distribution, update, removal).
  • BYOD (Bring Your Own Device): Funcionário usa dispositivo pessoal. Containerização, políticas.
  • COPE (Corporate Owned, Personally Enabled): Dispositivo da empresa com uso pessoal permitido.
  • CYOD (Choose Your Own Device): Funcionário escolhe de lista aprovada.

4️⃣ Embedded Systems

  • IoT (Internet of Things): Dispositivos conectados. Limitações: CPU, memória, energia. Segurança: segmentação, atualizações, trocar senhas padrão.
  • SCADA: Sistemas de controle industrial. Infraestrutura crítica. Isolamento (air gap), monitoramento.
  • RTOS (Real-Time OS): Tempo determinístico. Industrial, automotivo, médico. Previsibilidade > performance.
  • SoC (System on a Chip): Processador + componentes em um chip. IoT, mobile. Eficiência energética.

5️⃣ Email Security

ProtocoloDescrição
SPF (Sender Policy Framework)Registro DNS lista IPs autorizados a enviar email do domínio. Previne spoofing.
DKIM (DomainKeys Identified Mail)Assinatura digital do email. Valida integridade e autenticidade.
DMARC (Domain-based Message Authentication)Política para o que fazer quando SPF/DKIM falham (quarentena, rejeitar).
SMTP TLSCriptografia em trânsito entre servidores de email.
⚠️ REGRAS DE OURO:
  • Type 1: Bare metal (performance) | Type 2: Hosted (desenvolvimento)
  • SaaS: cliente não gerencia nada | PaaS: gerencia app+dados | IaaS: gerencia OS+app+dados
  • SPF: lista IPs | DKIM: assinatura | DMARC: política
  • VM Escape é o pior ataque em virtualização
