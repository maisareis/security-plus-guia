Capítulo 3: Soluções Criptográficas

🎯 CONCEITOS CRÍTICOS PARA A PROVA:
  • AES = padrão atual de criptografia simétrica
  • RSA = algoritmo assimétrico mais usado
  • SHA-256 = padrão atual de hash
  • MD5 e SHA-1 = obsoletos, não usar
  • Salt = essencial para hashing de senhas

3.1 Criptografia

Conceitos Fundamentais

  • Criptografia: Ciência de proteger informações através de codificação
  • Plaintext (Texto claro): Dados não criptografados
  • Ciphertext (Texto cifrado): Dados criptografados
  • Encryption (Criptografar): Converter plaintext em ciphertext
  • Decryption (Descriptografar): Converter ciphertext em plaintext
  • Key (Chave): Informação usada para criptografar/descriptografar
  • Algorithm (Algoritmo): Processo matemático usado

Objetivos da Criptografia

  • Confidencialidade: Apenas autorizados leem
  • Integridade: Dados não foram alterados
  • Autenticação: Verificar identidade
  • Não-repúdio: Não pode negar autoria

Criptografia Simétrica

  • Mesma chave para criptografar e descriptografar
  • Rápida e eficiente para grandes volumes
  • Problema: Como compartilhar chave com segurança?
  • Algoritmos: AES, DES, 3DES, Blowfish, RC4
  • Uso: Criptografia de disco, VPN, Wi-Fi (WPA2/WPA3)

Criptografia Assimétrica

  • Par de chaves: pública + privada
  • Chave pública: Pode ser compartilhada
  • Chave privada: Mantida em segredo
  • Lenta comparada à simétrica
  • Algoritmos: RSA, ECC, Diffie-Hellman, DSA
  • Uso: Assinaturas digitais, troca de chaves, SSL/TLS

Algoritmos Simétricos

  • AES (Advanced Encryption Standard): Padrão atual, 128/192/256 bits
  • DES (Data Encryption Standard): 56 bits, obsoleto, inseguro
  • 3DES (Triple DES): Aplica DES 3 vezes, sendo substituído por AES
  • Blowfish: Rápido, até 448 bits
  • Twofish: Sucessor do Blowfish
  • RC4: Stream cipher, obsoleto (WEP)

Algoritmos Assimétricos

  • RSA: Mais usado, assinaturas e criptografia, 2048+ bits
  • ECC (Elliptic Curve): Mesma segurança com chaves menores
  • Diffie-Hellman: Troca de chaves, base do HTTPS
  • DSA (Digital Signature Algorithm): Apenas assinaturas
  • ElGamal: Criptografia e assinaturas

Modos de Operação

  • ECB (Electronic Codebook): Inseguro, padrões visíveis
  • CBC (Cipher Block Chaining): Blocos encadeados, precisa IV
  • CTR (Counter): Modo stream, paralelizável
  • GCM (Galois/Counter Mode): Criptografia + autenticação

Blockchain

  • Ledger distribuído imutável
  • Cada bloco contém hash do anterior
  • Consenso distribuído (Proof of Work, Proof of Stake)
  • Usos: Criptomoedas, contratos inteligentes, supply chain

Esteganografia

  • Esconder mensagens dentro de arquivos (imagens, áudio, vídeo)
  • Diferente de criptografia (oculta existência vs oculta conteúdo)

Ataques Criptográficos

  • Brute Force: Testar todas combinações de chaves
  • Dictionary Attack: Testar palavras comuns
  • Rainbow Table: Tabela pré-computada de hashes
  • Birthday Attack: Explorar colisões de hash
  • Collision Attack: Encontrar dois inputs com mesmo hash
  • Downgrade Attack: Forçar uso de criptografia fraca

3.2 Implementações Criptográficas

Combinando Métodos

  • Hybrid Cryptography: Assimétrica para trocar chave simétrica
  • SSL/TLS: Usa assimétrica (handshake) + simétrica (dados)
  • PGP/GPG: Assimétrica + simétrica para email

Dispositivos de Hardware

  • TPM (Trusted Platform Module): Chip de segurança na placa-mãe
    • Armazena chaves criptográficas
    • Usado por BitLocker
    • Boot seguro
  • HSM (Hardware Security Module): Dispositivo dedicado para chaves
    • Alta performance
    • Tamper-resistant
    • Usado em bancos, CAs
  • Smart Card: Cartão com chip, armazena certificados
  • USB Security Token: Dispositivo USB para autenticação

3.3 Hashing

Conceito

  • Função one-way: Não pode ser revertida
  • Sempre mesmo tamanho de output (digest/hash)
  • Mesmo input = mesmo hash
  • Pequena mudança = hash completamente diferente (efeito avalanche)

Usos de Hash

  • Verificar integridade de arquivos
  • Armazenar senhas (com salt)
  • Assinaturas digitais
  • Blockchain
  • Certificados digitais

Algoritmos de Hash

  • MD5: 128 bits, obsoleto, vulnerável a colisões
  • SHA-1: 160 bits, obsoleto, vulnerável
  • SHA-2 (SHA-256, SHA-512): Padrão atual, seguro
  • SHA-3: Mais recente, alternativa ao SHA-2
  • RIPEMD: 160 bits
  • HMAC: Hash com chave secreta (MAC)

Salt

  • Valor aleatório adicionado antes do hash
  • Previne rainbow table attacks
  • Único para cada senha

3.4 Criptografia de Arquivos

EFS (Encrypting File System)

  • Windows, nível de arquivo/pasta
  • Transparente para usuário
  • Usa certificados do usuário

BitLocker

  • Criptografia de disco completo (FDE)
  • Requer TPM (ou USB key)
  • Protege contra theft de disco
  • BitLocker To Go para USB

PGP/GPG

  • PGP: Pretty Good Privacy (comercial)
  • GPG: GNU Privacy Guard (open source)
  • Criptografia de email e arquivos
  • Usa chaves públicas/privadas
  • Web of Trust

3.5 Public Key Infrastructure (PKI)

Componentes

  • CA (Certificate Authority): Emite certificados
  • RA (Registration Authority): Verifica identidade
  • CRL (Certificate Revocation List): Lista de revogados
  • OCSP (Online Certificate Status Protocol): Verifica status em tempo real
  • Certificate: Liga chave pública a identidade

Tipos de Certificados

  • Root Certificate: Auto-assinado, topo da hierarquia
  • Intermediate Certificate: Emitido por root, emite end-entity
  • Server Certificate: Para servidores web (HTTPS)
  • Client Certificate: Para autenticação de usuários
  • Code Signing: Para assinar software
  • Email Certificate: Para S/MIME
  • Wildcard: *.dominio.com
  • SAN (Subject Alternative Name): Múltiplos domínios
  • Self-signed: Não emitido por CA confiável

Conceitos PKI

  • Certificate Chain: Hierarquia até root CA
  • Trust Model: Quem confia em quem
  • Key Escrow: Terceiro guarda cópia da chave
  • Certificate Pinning: App aceita apenas certificado específico
  • OCSP Stapling: Servidor anexa resposta OCSP
